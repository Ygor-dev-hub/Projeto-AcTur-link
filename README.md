O Projeto AcTur é um sistema web simples de gerenciamento de transporte e viagens. Ele serve para:

Agendar e Consultar Viagens: Controlar para onde os veículos vão, datas, horários e passageiros.

Gerenciar Frota: Visualizar os veículos disponíveis, modelos, vagas e ano.

Controlar Acesso: Realizar login e cadastro de usuários no sistema.

Painel Inicial (Home): Exibir um resumo rápido com o status do dia (viagens, veículos e motoristas).
